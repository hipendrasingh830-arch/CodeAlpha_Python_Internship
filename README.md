Python Projects
This repository contains two simple Python projects:

Hangman Game
Stock Portfolio Tracker
Hangman Game
A classic word-guessing game where the player tries to guess a hidden word, letter by letter, within a limited number of incorrect guesses.

How to Play
Run the hangman_game.py script.
The game will display a series of underscores representing the letters of the hidden word.
Enter one letter at a time to guess letters in the word.
If the letter is in the word, it will be revealed.
If the letter is not in the word, you lose a guess.
The game ends when you guess the word or run out of guesses.
Features
Random word selection from a predefined list.
Tracks guessed letters and remaining incorrect guesses.
User-friendly interface.
Stock Portfolio Tracker
A simple command-line application to track a hypothetical stock portfolio based on hardcoded stock prices.

How to Use
Run the stock_portfolio_tracker.py script.
Enter stock symbols and quantities when prompted.
Type done when you are finished adding stocks.
The application will display a summary of your portfolio, including the total investment.
Features
Allows users to add multiple stocks and quantities to their portfolio.
Calculates the value of each stock holding and the total portfolio investment.
Provides a summary of the portfolio.
Getting Started
To run these projects, you will need Python installed on your system.

Clone this repository:
git clone https://github.com/your-username/your-repository-name.git
Navigate to the project directory:
cd your-repository-name
Run either of the scripts:
python hangman_game.py
# or
python stock_portfolio_tracker.py
